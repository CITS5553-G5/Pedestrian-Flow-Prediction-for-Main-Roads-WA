# Processed tables

`batch_input_dataset.xlsx` contains 50 current test locations in `Batch_Input`. For formal use, replace the rows with the chosen batch or supply another processed input file. The number of locations is not fixed. `model_dataset.xlsx` contains 49 surveyed model-development sites and their observed targets. Formal prediction matches new locations with the local Main Roads SLK snapshot in `../external_raw/`.
