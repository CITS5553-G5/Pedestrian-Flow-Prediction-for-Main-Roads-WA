# External source snapshots

`Mesh Block Counts, 2021.xlsx` supports ABS location features. `main_roads_slk/road_slk.sqlite.gz` is the local prediction-location reference: 73,275 measured road lines from the [Main Roads WA Road Network SLK Search dataset](https://catalogue.data.wa.gov.au/dataset/mrwa-road-network-slk-search), downloaded on 25 September 2026. It contains road numbers, SLK measures and carriageways, not RAP pedestrian counts. The predictor expands it to the system temporary directory; `python scripts/download_road_slk.py` refreshes the complete public snapshot without sending prediction locations.

The Commissioner of Main Roads is the creator and owner of that road data, available under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) with the source's disclaimer of warranties and limitation of liability. Review source changes before replacing the snapshot used for a recorded run. The [download-script guide](../../scripts/README.md) explains replacement behaviour and validation.

Research inputs use dated source folders: `microsoft_building_footprints/2026-07-24/` for building tiles, `overture_places/2026-08-19.0/` for nearby food and shopping places, `pta_stops/` for transport snapshots, `wa_education/2026_S1/` for the school workbook, and `wa_health_establishments/` for health source files. Some source snapshots are local and Git-ignored, so their presence on one computer does not imply they are included in a clone. Obtain the required snapshot through the documented source notebook or approved project storage and preserve its date and provenance.

Production Context uses only the ABS counts workbook; location resolution uses the measured Main Roads snapshot. The other sources support the retained [research notebooks](../../02_feature_extraction/README.md). Reviewed derived tables are indexed under [feature outputs](../../06_outputs/02_feature_extraction/README.md).
