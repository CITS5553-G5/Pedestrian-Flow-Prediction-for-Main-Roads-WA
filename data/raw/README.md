# Immutable raw data

Files in this directory are source evidence. Do not edit, overwrite, rename, or delete them during cleaning or analysis.

The supplied data currently include:

- three batches of macro-enabled pedestrian survey workbooks;
- `Road_Network.csv` with Road Number and SLK intervals;
- a large AusRAP road-segment workbook containing road attributes and raw BF/BG/BH exposure categories;
- `Ped_iRAP_merged.fst`, a small client-processed R/FST table that requires an R/FST export or a dedicated adapter before the Python pipeline can verify its contents.
