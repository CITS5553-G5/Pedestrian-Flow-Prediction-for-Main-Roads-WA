# Templates

`batch_input_template.xlsx` has three alternative input sheets: `Road_SLK` for `site_id` + road number + point SLK, `Coordinates` for `site_id` + WGS84 coordinate pair, and `Batch_Input` for both. Its 50 existing example rows in `Batch_Input` are test locations. Copy the chosen layout into a processed workbook for a formal run. `prediction_output_template.xlsx` is the maintained styled layout for `Prediction_Output`, `Features` and `Metadata`; the exporter fills it for any batch size. `model_dataset_template.xlsx` preserves the original modelling workbook for reference.
