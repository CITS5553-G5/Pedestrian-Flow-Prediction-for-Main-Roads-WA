# Templates

`batch_input_template.xlsx` has three alternative input sheets: `Road_SLK` for `site_id` + road number + point SLK, `Coordinates` for `site_id` + WGS84 coordinate pair, and `Batch_Input` for both. Its 50 existing example rows in `Batch_Input` are test locations. Copy the chosen layout into a processed workbook for a formal run. `prediction_output_template.xlsx` is the maintained styled layout for `Prediction_Output`, `Features` and `Metadata`; the exporter fills it for any batch size. `model_dataset_template.xlsx` preserves the original modelling workbook for reference.

The prediction template now uses `prediction_output_v5`: 29 output columns and an English/Chinese field dictionary, including existing AusRAP categories, derived bands and **Existing iRAP flow estimate (recoded)**. The input template and output filenames are unchanged. Observed counts are optional and stay blank for unknown sites. A processed input may optionally add `ausrap_record_id` for an exact original AusRAP record; see the [matching contract](../../docs/04_prediction_pipeline/ausrap_reference_integration_zh.md). No MAE/RMSE or separate side-flow columns are added.
