# Project documentation

The shared documentation follows the same stage numbers as the project folders.

- `01_data_preparation/` — Haoqi's shared table formats and verified source-data corrections.
- `02_feature_extraction/` — a concise summary of the fields produced by Haoqi's shared feature notebooks.
- `03_model_development/` — the pre-modeling protocol and feature-selection guidance.
- `04_prediction_pipeline/` — a proposed end-to-end architecture for team review; it is not the current implementation or a confirmed client requirement.

Detailed source research and personal implementation notes remain local and are not uploaded to GitHub.
